# Сборка

## Настройка окружения
Создайте файл `.env` в корневой директории проекта, по примеру из `.env.example`. Заполните его.

## Компиляция
Чтобы скомпилировать проект:
```bash
# в директории backend/bin/ появится исполняемый файл server
make build
```

```bash
# чтобы запустить скомпилированный проект
make run
```

## Прогон unit-тестов
Чтобы запустить unit-тесты:
```bash
make test
```

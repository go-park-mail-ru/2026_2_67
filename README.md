# Сборка на собственной машине

## Настройка окружения
Создайте файл `.env` в корневой директории проекта, по примеру из `.env.example`. Заполните его.

## Компиляция и сборка
Чтобы скомпилировать проект:
```bash
# в директории backend/bin/ появится исполняемый файл server
# запуск скомпилированного файла
make build && make run
```

## Прогон unit-тестов
Чтобы запустить unit-тесты:
```bash
make test
```

## Зависимости
- `PostgreSQL`
- `Redis`

# Сборка в Docker с docker-compose.

## Настройка окружения
Создайте файл `.env` в корневой директории проекта, по примеру из `.env.example`. Заполните его.

## docker compose

Соберите и запустите контейнеры:
```bash
docker compose up --build
```

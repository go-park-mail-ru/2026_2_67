### GET /api/v1/sellers[?searchParams=...]

Ручка нужна для того, чтобы предоставить **продавцов**, у которых продукты удовлетворяют `Query`-параметрам.

#### Request
`searchParams` передается как `QueryParameters`.
- `limit` = `Int` - максимальное количество, возвращается: `min{ДОСТУПНОЕ_КОЛИЧЕСТВО, limit}`.
- `category` = `[String, String, String...]` - продавцы, которые имеют продукты в этой категории.
- `query` = `String` - продавцы, которые имеют продукты, удовлетворяющие запросу `query`.
- `offset` = `Int` - какое количество `seller` требуется пропустить.
- `priceMin` = `Float` - минимальная цена товаров, если не указано = 0.
- `priceMax` = `Float` - максимальная цена товаров, если не указано = +inf.
- `ratingMin` = `Float` - минимальный рейтинг продуктов, если не указано, то 0.
- `ratingMax` = `Float` - максимальный рейтинг продуктов, если не указано, то 5.

Сортировка строго фиксирована на **беке**.\
Пока что сделано через пагинацию, так как продавцов на порядок меньше, чем товаров.

Если не указаны, то возвращается по критерию из бека.

#### Response
- Всегда правильный:
  - `status_code`: 200
  - `Body`:
  ```json
  {
    "sellers": [
      {
        "id": Int,
        "name": String
        "avatarUrl": String
      }
    ]
  }
  ```

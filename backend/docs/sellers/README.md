### GET /api/v1/sellers[?searchParams=...]

#### Request
`searchParams` передается как `QueryParameters`.
- `limit` = `Int` - максимальное количество, возвращается: `min{ДОСТУПНОЕ_КОЛИЧЕСТВО, limit}`.
- `category` = `String` - продавцы, которые имеют продукты в этой категории.
- `query` = `String` - продавцы, которые имеют продукты, удовлетворяющие запросу `query`.
- `offset` = `Int` - какое количество `seller` требуется пропустить.

Сортировка строго фиксирована на **беке**.\
Пока что сделано через пагинацию, так как продавцов на порядок меньше, чем товаров.

Если не указаны, то возвращается по критерию из бека.

#### Response
- Всегда правильный:
  - `status_code`: 200
  - `Body`:
  ```json
  {
    "sellers": [
      {
        "id": Int,
        "name": String
      }
    ]
  }
  ```

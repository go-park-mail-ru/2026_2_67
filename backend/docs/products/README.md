## API

### GET /api/v1/products[?searchParams=...]

#### Request
`searchParams` передаются как `QueryParameters`.
- `category` = `String` - название категории товаров
- `seller` = `String` - название продавца товаров
- `query` = `String` - строка, которая написана в поисковом поле
- `cursor` = `String` - специальная позиция курсора в БД для скроллинга
- `limit` = `Int` - количество, сколько стоит отдать продуктов (на бэке ограничен)
- `priceMin` = `Float` - минимальная цена, если не указано, то 0.
- `priceMax` = `Float` - максимальная цена, если не указано, то +INF.
- `sortBy` = `enum(new, popular)` - как именно должны быть отсортированы товары:
  - `new` - первыми идут те, которые вышли недавно.
  - `popular` - первыми идут популярные товары (условно, те у кого высокие оценки)
  - по умолчанию `new`.

`searchParams` являются опциональными:
- Если не один не указан, возвращается весь список (критерий регулируется на беке)
- Если указан один, то запрос учитывает ТОЛЬКО его.
- Если указаны несколько, то эти критерии логически соединяются через **И** (то есть: наушники **И** Apple).

Если в результате получается пустой результат, то отдаётся пустой результат.

#### Response
- Всегда правильный:
  - `status_code`: 200
  - `Body`:
  ```json
  {
    "products": [
      {
        "id": Int,
        "name": String,
        "pictureUrls": [
          String...
        ],
        "price": Float,
        "discount": Int,
        "priceResult": Float,
        "rating": Float,
        "reviewsCount": Int
      },
      "nextCursor": String,
    ]
  }
  ```
  Массив уже отсортирован по правильному критерию.

Если `nextCursor` является пустой строкой, то это страница является последней

### GET /api/v1/products/categories[?QueryParameters=...]

#### Request
`QueryParameters`:
- `limit` = `Int` - какое количество нужно.
- `sortBy` = `enum(new, popular)` - критерий отдачи.
  - `new` - первыми идут те, которые вышли недавно.
  - `popular` - первыми идут популярные категории (условно, те у кого больше всего продуктов)
  - по умолчанию `new`.

Если не указан `limit` возвращает **все**, иначе `min{ДОСТУПНОЕ_КОЛИЧЕСТВО, limit}`.

#### Response
- Всегда правильный:
  - `status_code`: 200
  - `Body`:
  ```json
  {
    "productCategories": [
      {
        "id": Int,
        "category": String,
        "pictureUrl": String
      }
    ]
  }
  ```

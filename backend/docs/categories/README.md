### GET /api/v1/categories[?searchParams=...]

#### Request
`Query`-параметры возможны:
- `limit` = `Int` - какое количество нужно.
- `sortBy` = `enum(new, popular)` - критерий отдачи.
  - `new` - первыми идут те, которые вышли недавно.
  - `popular` - первыми идут популярные категории (условно, те у кого больше всего продуктов)
  - по умолчанию `new`.
- `query` = `String` - запрос к продуктам, т.е. к тем которые удовлетворяют `query`.
- `priceMin` = `Float` - минимальная цена продуктов, если не указано, то 0.
- `priceMax` = `Float` - максимальная цена продуктов, если не указано, то +INF.
- `ratingMin` = `Float` - минимальный рейтинг продуктов, если не указано, то 0.
- `ratingMax` = `Float` - максимальный рейтинг продуктов, если не указано, то 5.
- `seller` = `[String, String, String...]`- категории продуктов, которые есть `seller`.

Если не указан `limit` возвращает **все**, иначе `min{ДОСТУПНОЕ_КОЛИЧЕСТВО, limit}`.

#### Response
- Всегда правильный:
  - `status_code`: 200
  - `Body`:
  ```json
  {
    "categories": [
      {
        "id": Int,
        "category": String,
        "pictureUrl": String
      }
    ]
  }
  ```
